Common Exception Types
ValueError: Wrong value type (int("abc"))
TypeError: Wrong data type (5 + "hello")
KeyError: Missing dictionary key
IndexError: List index out of range
FileNotFoundError: File doesn't exist
AttributeError: Object doesn't have that attribute
ZeroDivisionError: Division by zero
ImportError: Can't import module
Best Practices
1. Be Specific with Exceptions

# Catch specific exceptions first, general ones last
try:
    data = json.loads(file_content)
except json.JSONDecodeError:
    print("Invalid JSON")
except Exception as e:
    print(f"Unexpected error: {e}")
2. Use Context Managers (with statement)

# Automatically handles cleanup
with open("file.txt", "r") as f:
    content = f.read()
# File automatically closed, even if exception occurs
3. Don't Use Exceptions for Flow Control

# BAD
try:
    user = users[user_id]
except KeyError:
    user = None

# GOOD
user = users.get(user_id, None)
4. Log Exceptions Properly

import logging

try:
    risky_operation()
except Exception as e:
    logging.exception("Operation failed")  # Logs full traceback
    # or
    logging.error(f"Error: {e}", exc_info=True)
5. Clean Up Resources

# Pattern 1: Finally
file = None
try:
    file = open("data.txt")
    process(file)
except IOError as e:
    print(f"IO Error: {e}")
finally:
    if file:
        file.close()

# Pattern 2: Context Manager (preferred)
try:
    with open("data.txt") as file:
        process(file)
except IOError as e:
    print(f"IO Error: {e}")
Exception Hierarchy
Understanding the hierarchy helps you catch the right level:

BaseException
├── SystemExit
├── KeyboardInterrupt
└── Exception
    ├── ArithmeticError
    │   └── ZeroDivisionError
    ├── LookupError
    │   ├── IndexError
    │   └── KeyError
    ├── ValueError
    ├── TypeError
    └── ... many more
Key Takeaway: Catch Exception for general errors, but avoid catching BaseException (it includes system exits and keyboard interrupts).

Real-World Example

def read_config(filename):
    """Robust config file reader"""
    try:
        with open(filename, 'r') as f:
            data = json.load(f)
            
        # Validate required fields
        if 'api_key' not in data:
            raise ValueError("Missing required field: api_key")
            
        return data
        
    except FileNotFoundError:
        print(f"Config file {filename} not found")
        return None
    except json.JSONDecodeError as e:
        print(f"Invalid JSON in config: {e}")
        return None
    except ValueError as e:
        print(f"Config validation error: {e}")
        return None
    except Exception as e:
        print(f"Unexpected error reading config: {e}")
        raise  # Re-raise unexpected errors
